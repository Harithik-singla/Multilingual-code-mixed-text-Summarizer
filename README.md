# Multilingual Code-Mixed Text Summarization

## Project Overview

This project implements a deep learning-based abstractive text summarization system capable of handling code-mixed text across multiple Indian languages and English.

## Setup and Instructions

See the main project documentation for setup instructions and how to run each training phase and launch the app.

## Training Phases

- **Phase 1**: Train on monolingual ILSUM dataset
- **Phase 2**: Fine-tune on synthetic + real code-mixed data
- **Phase 3**: Optional stabilization training
